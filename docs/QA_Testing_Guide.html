ℹ Scope & Setup

How to open the editor

Navigate to Post Apo Map Editor/ and double-click MapEditorPro.html.
No server needed — works fully offline in any modern browser.

1 Mode Switching

1.1 Toolbar tabs

  • Click MAP tab → canvas and palette visible, paint/fill/rect tools shown in toolbar
  • Click HEX DB tab → hex list panel appears, map canvas hidden
  • Click BUILDINGS tab → buildings panel appears, HEX DB panel hidden
  • Click SETTLEMENTS tab → settlements panel appears, BUILDINGS panel hidden
  • Active tab has accent-colour highlight; all others do not
  • Toolbar buttons change per mode (Map tools / Add Hex / Add Building / Add Settlement)

1.2 Tab key cycling

Click an empty area of the page first to ensure no input is focused.
  • Press Tab → cycles MAP → HEX DB → BUILDINGS → SETTLEMENTS → MAP (loops)
  • Press Tab while an input field is focused → does NOT switch modes (normal browser tab behaviour)

1.3 Regression — MAP still works after switching

  • Switch MAP → BUILDINGS → SETTLEMENTS → MAP → canvas renders, paint tool works

2 BUILDINGS Mode

2.1 Empty state

  • Open BUILDINGS tab with no data → right panel shows "Drop building_database.json here or use 📂 Load DB"
  • Left panel shows 0 shown / 0

2.2 Add a building

  • Click + Add Building → new row (no id) appears in list, count becomes 1
  • Right panel shows form with 3 sections: MAIN, BUILD, LEVELS

2.3 MAIN section

  • Leave Id empty → red outline on the field
  • Type Barracks in Id → list row label updates immediately to Barracks, red outline clears
  • Fill TextId, SpriteName, BuildingType — values save without a Save button
  • Biome dropdown — switch to Winter, switch back to Summer
  • Set Max Level to 3 → exactly 3 level cards appear in LEVELS section
  • Set Max Level to 1 → only 1 level card remains

2.4 BUILD section

  • Click section header → collapses (▶), click again → expands (▼)
  • Collapse state is remembered after switching to another record and back
  • Fill Cost Gold, Cost Gems, Cost Event with numbers — values save correctly
  • Requires Road checkbox toggles correctly
  • Placement Rule and Max Per Map accept text/number input

2.5 LEVELS section

  • Set Max Level to 3 → Level 1, Level 2, Level 3 cards appear
  • Each level card has: Upgrade Gold, Upgrade Gems, Upgrade Condition, Transform To, Unlock List
  • Fill Level 2 → Upgrade Gold: 300, Upgrade Condition: PlayerLevel5
  • Fill Level 3 → Transform To: Barracks_Elite
  • Reduce Max Level to 2 → Level 3 card disappears; Level 2 data still intact
  • Increase Max Level back to 3 → Level 3 card reappears empty

2.6 Search

  • Add buildings: Barracks, Farm, PowerPlant — all 3 appear in list
  • Type bar in search → only Barracks shown, count updates
  • Clear search → all 3 shown

2.7 Duplicate id validation

  • Add a 4th building, set id to Barracks → Id field on duplicate shows red outline
  • Rename to unique id → red outline clears

2.8 Copy / Paste

  • Select Barracks → click Copy → toast "Copied Barracks"
  • Click Paste → new row Barracks_copy appears and is selected
  • Rename to Barracks_Elite — level data from Barracks is preserved in the copy

2.9 Delete

  • Select a building → click 🗑 Delete → confirmation dialog appears
  • Click Cancel → building NOT deleted
  • Delete again → confirm OK → building removed, count decreases
  • Select a building, press Delete key (no input focused) → confirmation dialog appears
  • Press Delete while typing in an input → does NOT trigger delete dialog

2.10 Save

  • Click 💾 Save DB → browser downloads building_database.json
  • Toast shows "Saved building_database.json"
  • Open the file — root keys are version and buildings
  • Each building entry has levels array with correct number of level objects
  • Each level object has: level, upgradePriceGold, upgradePriceGems, upgradeCondition, transformTo, unlockList

2.11 Load

  • Reload the page → click 📂 Load DB → select saved building_database.json
  • All buildings reappear in the list — toast "Loaded N buildings"
  • Click each building → all fields and level cards are correctly populated

2.12 Drag-drop load

  • Drag building_database.json from Finder and drop onto the BUILDINGS panel → same result as Load DB

2.13 Data menu

  • Menu bar → Data → Load Building DB… → file picker opens
  • Menu bar → Data → Save Building DB → downloads file

3 SETTLEMENTS Mode

3.1 Empty state

  • SETTLEMENTS tab → right panel shows "Drop settlement_database.json here or use 📂 Load DB"
  • Count shows 0 shown / 0

3.2 Add and fill a settlement

  • Click + Add Settlement → new row appears
  • Set id: Village, settlementType: Rural, Max Level: 3
  • BUILD section: set Cost Gold and Cost Gems

3.3 Unlock Buildings field per level

Key difference from BUILDINGS: each level card has an extra Unlock Buildings field — verify it is present.
  • Expand LEVELS → each card has 6 fields including Unlock Buildings (not present in Building level cards)
  • Level 1 → type Barracks,Farm in Unlock Buildings
  • Level 2 → type PowerPlant
  • Switch to a different settlement and back → Unlock Buildings values are still there

3.4 Multi-level settlements

  • Add Town with Max Level: 5 → exactly 5 level cards
  • Add City with Max Level: 8 → exactly 8 level cards

3.5 Save and load round-trip

  • Save → open settlement_database.json — root keys: version, settlements
  • Each level object includes unlockBuildings key
  • Reload page → Load DB → all data survives round-trip

3.6 Data menu

  • Menu bar → Data → Load Settlement DB… and Save Settlement DB both work

4 Cross-Mode Consistency

  • Load building_database.json in BUILDINGS → switch to SETTLEMENTS → switch back to BUILDINGS → data still loaded
  • Load settlement_database.json in SETTLEMENTS → switch to MAP → draw on canvas → switch back to SETTLEMENTS → settlement data intact
  • HEX DB data is unaffected by BUILDINGS or SETTLEMENTS operations

5 MAP Mode — Regression

  • Paint tool: click and drag on canvas paints selected terrain
  • Fill tool: flood-fills a connected region
  • Rectangle tool: drag to fill a rectangular area
  • Eyedropper: click a tile to select its terrain type
  • Settlement placement and erase tools work
  • Zoom in/out via View menu and mouse wheel
  • File → Save → map.json downloads correctly
  • File → Open → previously saved map reloads correctly
  • Undo / Redo (Ctrl+Z / Ctrl+Y) work

6 HEX DB Mode — Regression

  • Click HEX DB tab → empty state shown with drag-drop prompt
  • + Add Hex → blank hex record appears in list
  • Fill id, biome, type → list row label updates, biome badge shows correct colour
  • Biome and Type dropdowns filter the list correctly
  • Search box filters by id
  • 💾 Save DB → hex_database.json downloads
  • 📂 Load DB → reload saved file → data is identical
