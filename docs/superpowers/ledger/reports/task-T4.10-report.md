What: `MapEditorPro.html` History EXTENDED (not replaced) and `tests/history-panel.spec.ts` (8 tests).
- Kept: token return (now also carries `meta`, `evictedMeta`, `redoMeta`), `rollback`, fill/stroke gating in undo/redo, row sharing and `_last`, `debugRowCount`, Ctrl+Z/Y.
- New API: `push(label?)` (default 'Edit'), `getEntries() -> {done, undone}` (undone in redo order), `jumpBy(n)`, `onChange(fn)`, `initPanel()`, `debugRestoreCount()` (test counter).
- Meta arrays `_undoMeta/_redoMeta` changed in lockstep in push (evict + redo clear), undo, redo, rollback (evicted entry and redo labels come back), clear. `_restore` never touches the stacks.
- Panel: collapsed `<details id="history-panel">` in the left palette (`#palette-panel`), `#history-list` of real `button.hist-row` (textContent, title with time), newest first, undone rows italic, current row `.current` + `aria-current`. Rendered through `onChange` (no polling). Shown rows capped at 50 (nearest 25 undone + the rest done). Keyboard Enter/Space jump and focus is restored on the current row after the re-render; pointer click blurs the button (the canvas takes no focus; same convention as Go to).
- `jumpBy`: N public-undo/redo bodies, clamped to the available steps (stacks are capped at 50, so at most 50 restores); render, minimap, validator mark, panel refresh and toast happen ONCE (batch flag skips them for the intermediate steps). Refused with a toast while `isFillBusy()`, `isStroking()` (eraser/lazy stroke, lifted move) or `isStrokeActive()` (a mouse gesture). Ctrl+Z/Y still toast per step as before.
- Labels (no behaviour change): Paint, Fill, Rectangle/Line/Circle/Polygon (`TOOL_NAMES[_active]`), Zone paint, lazy stroke tools via `_pushOnce` (Eraser, Scatter, Place Building, Erase Building, Draw Road, Connect Road, Erase Road, Place Bridge from `TOOL_NAMES`), Place/Erase settlement, Move City, Move, Paste (stamps place via paste), Cut, Delete, Replace tile, Settlement slot, Distance bands, Clear map, Fill map, Generate map/region, Apply satellite, Place all tiles, Placement, Auto-place settlements, Open map, Expand map.
