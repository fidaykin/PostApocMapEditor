# T4.2 report: Bookmarks

Where: MapEditorPro.html. Module `Bookmarks` (above the Brush banner): `initPanel, add, rename, remove, go, list, isAvailable, render, refresh`. Panel `#bookmarks-panel` (`#bm-name`, `#bm-add-btn`, `#bookmarks-list` with real `<button>`s `.bm-go/.bm-ren/.bm-del`) in the LEFT palette between Go to and Stamps. Started from the load handler in a try/catch like Stamps/Layers. CHANGELOG entry. tests/nav-bookmarks.spec.ts (new, 15 tests).

Decisions
- Scope: per BROWSER (key `mapEditorBookmarks.v1`, `{v:1, items:[{id,name,col,row,zoom}]}`), never in the map JSON/autosave/History (a map has no stable identity). Test proves the saved map JSON contains no bookmark text and History/map are untouched.
- Out-of-bounds cells (New map smaller, other map): the jump button is `disabled` + `.bm-off` + title "Outside this map (W x H)"; rename/delete still work; `go()` returns false with a toast and does not move the view; re-enabled when the size changes back. `refresh()` is called (cheap size signature) from `UI.updateStatusSize`, `Canvas.reclampZoom`, `newMap(silent)`, `_restoreMapState` and the autosave restore (a first test run showed `IO.newMap(true)` had no hook: fixed).
- Safety: names rendered with textContent/attributes only; cap 50 items, names 40 characters (control chars stripped, whitespace collapsed, empty -> "col,row"); load tolerates corrupt JSON, wrong shapes, non-integer/negative/huge cells, bad zoom (->100), duplicate/invalid ids (regenerated), >50 items; blocked getItem/setItem: in-memory for the session, ONE warning toast.
- Input: Add button / Enter in the name field; Escape blurs; typing never reaches map shortcuts; Enter/Space on the buttons do not reach Space-pan/Enter-lift; pointer clicks blur the button (focus back to the map shortcuts), keyboard keeps focus (after a keyboard delete focus moves to the next row, or the name field when empty). Rename uses `UI.showModal` (`#bookmark-rename-modal`, text input preselected, Enter renames, empty refused, Escape cancels, focus returns to the row's rename button).
- Jump = `Canvas.setZoom(saved) + centerOnTile`; no History step, no gate (tested during an active stroke).
- No shortcut (plan's Shift+B dropped; none needed).

Process note: the module was written before the spec (RED-first slip); RED was then recorded by temporarily restoring the HEAD file (15/15 failed: no `Bookmarks`/`#bm-add-btn`), implementation restored byte-identical (cmp), then GREEN.
GREEN: nav-bookmarks 15/15 (after fixing 2 test-side issues: macOS Ctrl+A is "home", the reloaded session opens a small map). Focused run: nav-bookmarks, nav-goto, layout-narrow, stamps, layers, shortcut-layouts, modal, storage-errors = 344 passed, 0 failed (2.2 min). Perf specs not run (no render/pan/zoom code touched). Sanity mutation (textContent -> innerHTML, bounds check off): 3 tests failed; restored (cmp clean). Weak spot: the `go()` bounds guard is also guarded by `centerOnTile`, so removing only the toast check is not caught.
FYI / owner: bookmarks list on every map (browser-wide); Expand Map does not shift coordinates in the bookmark, so after an expand that moves the origin a bookmark points at the same cell numbers, not the same content (not changed here).
