# T4.4 report: shortcut registry and help panel

What / where (MapEditorPro.html, CHANGELOG.md, tests/shortcuts.spec.ts, tests/shortcut-layouts.spec.ts):
- `Shortcuts` module above `// -- App: mode switching`, init after `IO.initKeyboard()`. API: `register`, `getAll` ([{id,group,keys,display,label,bound}]), `resolve(e)` (pure), `showHelp()`.
- Single table. Entries WITHOUT `run` document keys other handlers own (never executed here, so no key is handled twice); entries WITH `run` are the new keys: `+`/`=` zoom in, `-` zoom out, `0` fit, `1`/`2`/`3` rings / rulers / coastline. Tool entries are DERIVED from the Tools dispatcher's own tables via new exports `Tools.toolKeys()` / `Tools.toolNames()` (cannot drift); Ctrl combos, Delete/Enter/Esc, `[` `]`, float keys `. , / ;`, Space pan, Tab are listed by hand and every one is pressed by the spec.
- Matching: letter entries follow the typed-letter rule (typed Latin letter decides, physical key only where no Latin letter is typed; `fallback`/`noShift` mirror the Tools tables); non-letter entries match the typed character (`e.key`, Shift ignored so AZERTY digits work). Never with Ctrl/Meta/Alt, IME composition, key names, `defaultPrevented`, outside map mode, while typing or a modal is open: uses the NEW export `Tools.isTypingOrModal(e)` (the same function the tool keys use). Repeat only for zoom. When a paste float is active the Slash/Period/Comma/Semicolon codes belong to the float (QWERTZ types `-` on Slash: mirror once, no zoom).
- Key decisions per rulings: dropped the plan's `G`, `M`, `C`, `Shift+B`, `?`; no key opens help (F1 and `?` left alone: every free key is spoken for; Shift+/ would share a physical key with the float mirror); `[` `]` documentation-only (Tools owns them, so no double step). Help opens from a "Keyboard shortcuts" button in the LEFT palette (`#btn-shortcut-help`) and from View > Keyboard Shortcuts.
- Help = `UI.showModal` with DOM nodes only (h4 per group, table rows, `td` textContent); generated from `getAll()`.
- shortcut-layouts spec: hand-written per-layout zoom expectations for all nine rows (only QWERTZ types `-` on a letter-row key, Slash = zoom out; every other press must not zoom) plus the registry resolver must agree with every press (tool id or null) in all nine layouts.
