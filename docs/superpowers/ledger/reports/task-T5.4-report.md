# T5.4 report: sprite upload validation, name safety, collisions, per-package routing
Changed: MapEditorPro.html; new tests/packages-sprite-upload.spec.ts (10 tests).
- `Packages.normalizeSpriteFile(file)`: size cap 4 MB checked from file.size alone (nothing read), 64 KB header sniff (real PNG/JPEG/WebP only; SVG rejected by name, type or content; text/truncated/corrupt rejected), max 2048x2048 read from the PNG/JPEG/WebP header BEFORE decoding (decompression bomb never decoded), PNG returned untouched (same File), JPEG/WebP converted to PNG through a canvas, non-512x512 gives a warning, bitmap closed, no object URLs.
- `Packages.sanitizeSpriteName`: basename only (/ and \), extension dropped, control chars and `..` removed, `<>:"|?*#%` -> `_`, 64 chars, null when nothing is left.
- `Packages.checkSpriteName(pkg,name,category)`: 'self' = the package's own store (any category: the store key is the name only) or, for postapoc, a sprite the DBs reference in that category (it lives on the server pool: overwriting would be silent); 'postapoc' = non-default package name equals a base sprite (toast only, stored separately).
- `UI.handleSpriteUpload`: queued (one batch at a time), per file: validate -> sanitise -> collision modal via UI.showModal (Replace / Keep both -> `name_2`.. / Cancel; resolves once for button, Escape, backdrop) -> optimise -> read -> `SpriteStore.save(name, url, cat, pkg)` + `registerUploadedUrls(keyFor)`. Nothing is stored if any earlier step fails. Pushed to the server pool only for postapoc (other packages ship on publish). Multi-file: one summary toast "N uploaded, M skipped". `UI.prepareSpriteUpload` is exported and shared.
- Content manager `_cmUploadSprite` now uses the same validation/sanitising/collision flow and saves explicitly to `postapoc`; accept widened to png/jpeg/webp. `migrateToBuilding` reads/saves the sprite in the hex's package namespace (pushes only for postapoc, fallback fetch from the hex's package folder); the new building keeps `package` when the hex is not postapoc (before, it silently became a postapoc building).
