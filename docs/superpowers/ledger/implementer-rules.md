# Standing rules added during Phase 2 (read these; they come from real review findings)
- TESTS MUST BE REAL: write them RED first and show the failing run; no vacuous assertions (`>= 1` on something that is always true; `window.x = ...` on top-level `let` bindings such as mapData/MAP_WIDTH — assign the bare binding inside page.evaluate); independent references (computed from pixel geometry `Canvas.hexCenterWorld`, not from the code under test); NO wall-clock assertions (count work, ticks, calls, or compare ratios in the same page); keep tests cheap (bare maps, few renders at low zoom).
- MUTATION PATHS: any cache/overlay/derived state must be correct for every way map data changes (paint/fill/rect/shapes, undo/redo (in place), New/Load/Expand (reassign), autosave restore, side-copy restore, generator/satellite apply). Revalidate against live data or enumerate every site and test each.
- INPUT HANDLING: only the left button starts tool actions; right/middle/space pan; mouseup outside the canvas and window blur must finish or cancel cleanly; Escape cancels without a History step; tool switch resets all drag state; a map replacement mid-gesture cancels with a toast; `Tools.isFillBusy()` gates tool input; tool shortcuts follow the TYPED letter on Latin layouts and the physical key (`e.code`) only where no Latin letter is typed (Cyrillic, Greek; punctuation for the tools that have a physical key); key names (Dead, Process, Unidentified), IME composition, Alt and repeat never trigger them; Ctrl/Cmd shortcuts are unchanged (physical key for A/C/X/V/D, typed letter for undo/redo); shortcuts respect `_isTypingOrModal`, never collide with P F R E S T D Z L O G [ ] Ctrl+N/O/S/Z/Y Ctrl+Shift+S Tab Space.
- ONE History step per user gesture; History.push BEFORE the first write; autosave scheduled after.
- RENDERING: output at zoom >= 25% must stay pixel-identical (tests/perf-baseline.json is guarded; never edit/regenerate it; the `fill_scene` key is stale by design). Adding controls to the TOP TOOLBAR widens the page/canvas (it is a non-wrapping 1931 px row) and breaks hash baselines (canvas 1491x808 at 1400x900): put new controls in the left palette or a panel that does not change the canvas width.
- GEOMETRY: use HexUtils (cube math, neighbours, lines, discs, polygon). Never use the legacy `_DIRS_EVEN/_ODD` tables in new code (K1); EdgeTiling still reads masks through them, so edge re-resolution discovers cells over true plus legacy neighbours (already implemented in `_autoResolveEdgesAround`).
- HARNESS: tests/README.md. The full suite takes ~6 min; the harness keeps the Mac awake and caps startup. Run the full default suite ONCE at the end (never overlapping runs, never leave background runs behind: kill what you start); report wall time, failures, `startup retries: N`, and `uptime`. Failures caused by load/sleep must be re-run alone and reported as such, not hidden. Implementer reports must not claim 'N passed' without a clean run.
