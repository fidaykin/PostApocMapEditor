# Pattern brush (патерн-пензлик): дизайн

Статус: **погоджено власником варіант A** (2026-11-17), реалізація в гілці `feat/pattern-brush`.

## Навіщо
Замальовувати великі площі мапи фрагментом іншої мапи, як штамп-патерн у Photoshop: пензлик малює не одним тайлом, а патерном, який
повторюється плиткою. Патерном може бути збережений штамп, виділена ділянка або вся мапа (файл з сервера чи локальний).

## Рішення власника
- Варіант A: патерн **прив'язаний до сітки мапи**. Клітинка `(col,row)` бере клітинку патерна `[(row - oy) mod h][(col - ox) mod w]`.
  Мазки, зроблені в різний час, стикуються без швів.
- Механізм має бути **гнучким**: команда може змінити правило або додати можливості без переписування інструмента.

## Що ми вирішили самі (позначено як припущення)
- Пише лише шар terrain (`mapData`). Будівлі, дороги й зони не чіпає. Контракт джерела вже має місце для шарів, щоб додати їх пізніше.
- «Прозорі» клітинки: клітинки патерна, чиї id в списку `skip`, не малюються (за замовчуванням список порожній, малюється все).
- Непарна висота патерна: гекс-сітка зсуває непарні рядки, тому патерн, що повторюється через `h` рядків, змінює парність. Це відомо й
  описано в документі; для непарної висоти пропонується ставити `h` парним (мапа 50x50 парна).

## Архітектура: три шви розширення
Усе ядро живе в `pattern-brush.js` (чисті функції, без DOM; тестується в Node). Редактор лише підключає його до пензлика.

1. **Pattern** (контракт даних): `{ name, w, h, ids: (string|null)[] }`, рядок за рядком, `null` = порожньо. Єдине, що знає ядро.
2. **Source** (звідки береться патерн): реєстр `registerSource(key, { label, load(arg) -> Pattern })`. Вбудовані: `map` (JSON мапи: `data`),
   `selection` (виділення), `stamp` (штамп). Нове джерело = одна функція; ядро й інструмент не змінюються.
3. **Mapper** (яка клітинка патерна лягає в клітинку мапи): реєстр `registerMapper(key, { label, pick(pattern, col, row, opts) -> id|null })`.
   Вбудований `grid` (варіант A). `click` (від точки кліку) і `random` (випадкове вікно) додаються однією функцією, без правок інструмента.

Параметри мазка: `{ mapper, ox, oy, skip: string[] }`; невідомі поля зберігаються в `opts`, тож mapper може мати власні.
Розрахунок: `cellsFor(cells, pattern, opts) -> [{col,row,id}]` (чиста функція; редактор передає результат у `_writeTerrain`, як Scatter).

## Інтеграція в редактор
- Інструмент `pattern` поруч із Scatter (клавіша, кнопка Quick bar, рядок налаштувань: джерело, зсув X/Y, skip).
- Розмір пензля й симетрія працюють, як у Paint/Scatter. Один мазок = один крок Undo.
- Джерело `map`: список мап із сервера (`maps/map_list.json`) і «Open file…».

## Не робимо зараз
Mapper `click` і `random`, шари objects/roads/zones, повертання/віддзеркалення патерна. Для них залишено шви, але коду немає.
