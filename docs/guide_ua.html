MapEditorPro v0.4.6

Посібник користувача  ·  Українська  ·  Оновлено 2026-05-06

1. Вступ

MapEditorPro — це браузерний редактор hex-карт на чистому JavaScript, який не потребує встановлення. Версія 0.4.6 містить чотири інтегровані інструменти в одному HTML-файлі: Редактор карти, Редактор бази даних Hex, Редактор будівель та Редактор поселень. Інструмент розроблений для ізометричних стратегій і градобудівників на основі шестикутних сіток.

Оскільки весь застосунок — це один файл .html без серверної частини, він повністю працює офлайн і не потребує інсталяції.

Системні вимоги

  • Браузер: рекомендується Google Chrome 90+ або Microsoft Edge 90+ (на базі Chromium). Firefox підходить для редагування карти; функція автозбереження до теки потребує File System Access API (тільки Chrome/Edge).
  • Екран: мінімум 1200 px завширшки для комфортного відображення.

Відкриття редактора

  1. Знайдіть файл MapEditorPro.html у теці проекту.
  2. Перетягніть файл у відкрите вікно Chrome або Edge, або двічі клацніть його, щоб відкрити у браузері за замовчуванням.
  3. Якщо Chrome запитує дозвіл на доступ до файлів (для автозбереження), натисніть Дозволити.

2. Огляд інтерфейсу

Редактор розділений на три горизонтальні смуги: рядок меню вгорі, панель вкладок під ним та основна робоча область нижче. Робоча область завжди складається з вузької лівої панелі, центрального полотна або списку та вужчої правої панелі. Перемикання між чотирма вкладками одночасно змінює вміст усіх панелей.

3. Редактор карти

Вкладка MAP — основна робоча область з полотном. Тут ви малюєте ландшафт на hex-сітці, керуєте поселеннями, а також експортуєте або зберігаєте карту.

Палітра ландшафту

Клацніть на зразок ландшафту, щоб обрати його як активний; обраний елемент підсвічується акцентним кольором і відображається у блоці Активний ландшафт правої панелі.

Масштаб і переміщення

Hex-полотно підтримує масштаб від 25% до 400%. Переміщуйте полотно, утримуючи Space і перетягуючи, або за допомогою середньої кнопки миші. Поточний рівень масштабу відображається в правому нижньому куті полотна.

Макет — полотно з індикатором масштабу та курсором переміщення

  • Колесо миші — збільшення/зменшення масштабу відносно позиції курсора.
  • Ctrl + + / Ctrl + - — збільшення/зменшення на один крок.
  • Ctrl + 0 — скинути масштаб до 100%.

Увага: при масштабі менш ніж 50% межі окремих hex-клітинок приховуються, щоб зменшити візуальний шум.

Клацніть або перетягніть всередині мінікарти, щоб перемістити основне полотно до відповідної позиції. Нижче мінікарти розміщені селектор Розмір пензля, блок Активний ландшафт та лічильник Поселень.

Збереження та завантаження карт

Карти зберігаються як JSON-файли, що містять сітку терейну, позиції поселень і метадані. Використовуйте меню File або гарячі клавіші для роботи з файлами карт.

  • New Map (Ctrl+N) — запитує розміри карти та створює порожню сітку.
  • Open (Ctrl+O) — відкриває вибір файлу; оберіть будь-який файл карти .json.
  • Save (Ctrl+S) — завантажує поточну карту у браузері як map_session.json.
  • Export CSV — експортує сітку терейну у файл з комами як роздільниками (рядок × стовпець, ID терейну у кожній клітинці).
Додаткові пункти меню Edit: Undo (Ctrl+Z), Redo (Ctrl+Y), Clear Map (скинути всі hex), і Fill Map (залити всю карту активним терейном).

Автозбереження до папки

Редактор автоматично зберігає карту до localStorage браузера після кожної зміни. Якщо ви випадково закрили вкладку, повторне відкриття редактора автоматично відновить останній стан.

Для постійних резервних копій у файловій системі скористайтесь File → Set Autosave Folder…. Відкриється системний вибір папки. Редактор створить підпапку saved_maps/ всередині обраної папки та записуватиме туди map_session.json після кожної зміни.

Сумісність із браузерами: File System Access API, що використовується для автозбереження, доступний лише у Chrome та Edge. У Firefox і Safari вибір папки не відкриється; скористайтесь Ctrl+S для ручного збереження завантаженням.
Порада: Вкажіть папку автозбереження, синхронізовану з хмарою (Dropbox, Google Drive, OneDrive), для автоматичного резервного копіювання поза пристроєм.

4. Редактор HexDB

Вкладка HEX DB — це повноцінний редактор бази даних для кожного типу терейну та об'єктів, що використовуються на карті. Кожен запис бази (так званий "hex") визначає ігрові властивості: зовнішній вигляд, можливість знищення чи будівництва, генерацію доходу та особливу поведінку.

Вкладка розділена на лівий список і праву форму деталей. Вибір запису зі списку миттєво завантажує його дані у форму.

Додавання та керування записами hex

Лівая панель показує всі записи hex у порядку A-Z. Поле пошуку та два фільтри-dropdown (Biome і Type) звужують список у реальному часі. Нижній рядок показує загальну кількість записів і кнопку Delete для вибраного запису.

Секція INCOME

Секція INCOME налаштовує генерацію ресурсів. У верхньому рядку розміщено два головних toggle: Tap Income (блокує ланцюг доходу, що активується натисканням) і Destroyable (блокує ланцюг трансформації при натисканні). Обидва незалежні. Поля Per Turn і постійного доходу завжди видимі та активні незалежно від toggle.

  • Tap Income — вмикає видачу ресурсів за натискання. Активує Capacity та блок Get per Tap.
  • Destroyable — вмикає трансформацію при натисканні. Активує dropdown Transform to і Parent Hex.
  • Capacity — кількість натискань, яку hex може прийняти перед трансформацією (мінімум 1, типово 3).
  • Get per Tap — динамічний блок ресурсів; кожне натискання надає ці ресурси гравцю.
  • Per Turn — завжди активний; ресурси генеруються кожен ігровий хід незалежно від взаємодії.
  • Spend Constant — ресурси, що витрачаються за хід (використовується для забруднення, споживання енергії, обслуговування).

Секція SPECIAL

Секція SPECIAL обробляє бонусні нагороди, тригерні події та заблоковані заповнювачі для Boosters і Effects, що будуть додані у майбутніх версіях.

  • Bonus Drop — головний toggle; якщо вимкнено, поля Triggers і Bonuses деактивовано.

  • Boosters і Effects — заблоковані заповнювачі; ці поля будуть розблоковані у майбутній версії.

Копіювання/вставлення та збереження БД

Всі дані hex зберігаються в пам'яті під час редагування. Використовуйте дії toolbar для збереження змін:

Макет — дії toolbar HEX DB
+ Додати Hex 📂 Завантажити БД 💾 Зберегти БД
✓ Збережено 14:32
29 записів у базі даних  ·  Останнє збереження: hexdb_v0.4.6.json
  • 📂 Load DB — відкриває вибір файлу для завантаження файлу hex-бази .json, замінюючи поточну базу в пам'яті.
  • 💾 Save DB — завантажує всю базу даних як файл .json. Зберігайте часто; у формі БД немає історії скасування.
Увага: Завантаження нового файлу БД негайно замінює поточну базу в пам'яті. Всі незбережені зміни буде втрачено. Завжди використовуйте Save DB перед завантаженням іншого файлу.
Прийом для дублювання: Щоб скопіювати запис hex, відкрийте JSON-файл у текстовому редакторі, продублюйте об'єкт, призначте новий ID і перезавантажте через Load DB.

Вкладка BUILDINGS керує каталогом будівель, які можна розміщувати на hex карти. Її структура повторює HEX DB: список із пошуком ліворуч і форма деталей праворуч.

Форма правої частини має три секції, що згортаються:

  • MAIN — Id, TextId, описи, sprite і Max Level. Max Level приймає будь-яке значення ≥ 1 без верхнього обмеження.
  • BUILD — правила розміщення та ціна, аналогічно секції BUILD для hex.
  • LEVELS — вартість покращення, значення доходу та модифікатори характеристик для кожного рівня. Рядки додаються/видаляються динамічно відповідно до значення Max Level.
Дані будівель зберігаються незалежно від Hex DB. Id будівлі посилається на карту через маркери поселень, а не безпосередньо через плитки hex.

6. Редактор поселень

Вкладка SETTLEMENTS визначає типи поселень, які можна розміщувати на карті за допомогою інструменту Settlement (⬡). Поселення є іменованими зонами, що складаються з кількох hex і можуть посилатись на набір дозволених будівель.

Форма повторює структуру Редактора будівель:

  • MAIN — Id, TextId, описи, sprite і Max Level (без верхнього обмеження).
  • BUILD — обмеження плиток, мінімальний рівень гравця та вартість будівництва.
  • LEVELS — рядки даних для кожного рівня; кількість визначається значенням Max Level.
Лічильник поселень, що відображається на правій панелі вкладки MAP, показує кількість маркерів поселень, розміщених на полотні, а не кількість визначень поселень у цьому редакторі.

7. Гарячі клавіші

Всі гарячі клавіші доступні глобально, поки вкладка MAP у фокусі. Форми DB/Buildings/Settlements перехоплюють введення з клавіатури для своїх полів і не реагують на гарячі клавіші інструментів.
