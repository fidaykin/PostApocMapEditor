MapEditorPro v0.4.6

User Guide  ·  English  ·  Last updated 2026-05-06

1. Introduction

MapEditorPro is a browser-based, zero-install hex-tile map editor written in vanilla JavaScript. Version 0.4.6 ships four integrated tools in a single HTML file: a Map canvas editor, a Hex Database editor, a Buildings editor, and a Settlements editor. It is designed for top-down strategy and city-builder games that use hexagonal tile grids.

Because the entire application is a single .html file with no server-side component, it works completely offline and requires no installation.

System requirements

  • Browser: Google Chrome 90+ or Microsoft Edge 90+ (Chromium-based) recommended. Firefox works for map editing; the autosave-to-folder feature requires the File System Access API (Chrome/Edge only).
  • Screen: 1200 px wide minimum for a comfortable layout.

Opening the editor

  1. Locate MapEditorPro.html in your project folder.
  2. Drag the file onto an open Chrome or Edge window, or double-click it to open in your system default browser.
  3. If Chrome asks for file-access permission (for autosave), click Allow.

The editor is divided into three horizontal bands: a menu bar at the very top, a tab toolbar directly beneath it, and the main workspace below. The workspace is always split into a narrow left panel, a central canvas or list view, and a narrower right panel. Switching between the four tabs changes every panel simultaneously.

3. Map Editor

The MAP tab is the primary canvas workspace. You paint terrain onto a hex grid, manage settlements, and export or save your map from here.

Terrain Palette

The left panel lists all 29 terrain types, organized into collapsible category groups (e.g., Natural, Urban, Wasteland, Water). Click any category header to expand or collapse it. Click a terrain swatch to select it as the active brush terrain; the selected entry is highlighted in the accent color and mirrored in the right panel's Active Terrain display.

Zoom and Pan

The hex canvas supports zoom from 25% to 400%. Pan by holding Space and dragging, or by using the middle mouse button. The current zoom level is displayed in the bottom-right corner of the canvas.

  • Ctrl + + / Ctrl + - — zoom in/out by one step.

When zoomed below 50%, individual hex borders are hidden to reduce visual noise.

Saving and Loading Maps

Maps are saved as JSON files that store the terrain grid, settlement positions, and metadata. Use the File menu or keyboard shortcuts to manage map files.

Mockup — File menu

Click a menu item or use the keyboard shortcut
  • New Map (Ctrl+N) — prompts for map dimensions, then creates a blank grid.
  • Open (Ctrl+O) — opens a file picker; select any .json map file.
  • Save (Ctrl+S) — triggers a browser download of the current map as map_session.json.
  • Export CSV — exports the terrain grid as a comma-separated values file (row × column, terrain ID per cell).
Edit menu extras: Undo (Ctrl+Z), Redo (Ctrl+Y), Clear Map (reset all hexes), and Fill Map (flood the entire map with the active terrain).

Autosave to Folder

The editor auto-saves your map to browser localStorage after every change. If you close the tab accidentally, reopening the editor will restore the last state automatically.

For persistent file-system backups, use File → Set Autosave Folder…. This opens a system folder picker. The editor creates a saved_maps/ subdirectory inside the chosen folder and writes map_session.json there after every change.

Browser compatibility: The File System Access API used for autosave is available in Chrome and Edge only. In Firefox and Safari the folder picker will not appear; use Ctrl+S to download a manual save instead.
Tip: Set the autosave folder to a cloud-synced directory (Dropbox, Google Drive, OneDrive) for automatic off-device backup.

4. HexDB Editor

The HEX DB tab is a full database editor for every terrain and object type used on the map. Each database entry (a "hex") defines gameplay properties: how it looks, whether it can be destroyed or built upon, what income it generates, and any special behaviors.

The tab is split into a left list and a right detail form. Selecting an entry in the list loads its data into the form immediately.

Adding and Managing Hex Entries

The left panel shows all hex entries sorted A-Z. A search field and two filter dropdowns (Biome and Type) narrow the list in real time. The footer shows the total entry count and a Delete button for the selected entry.

Copy/Paste and Save DB

All hex data is stored in memory as you edit. Use the toolbar actions to persist changes:

Mockup — HEX DB toolbar actions
+ Add Hex 📂 Load DB 💾 Save DB
✓ Saved 14:32
29 entries in database  ·  Last saved: hexdb_v0.4.6.json
  • 📂 Load DB — opens a file picker to load a .json hex database file, replacing the current in-memory database.
  • 💾 Save DB — downloads the entire database as a .json file. Save frequently; there is no in-database undo history.
Important: Loading a new DB file replaces the current database in memory immediately. Any unsaved changes will be lost. Always Save DB before loading a different file.
Duplicate trick: To copy a hex entry, open the JSON file in a text editor, duplicate the object, assign a new ID, and reload with Load DB.

The right-side form has three collapsible sections:

  • MAIN — Id, TextId, descriptions, sprite, and Max Level. Max Level accepts any value ≥ 1 with no upper limit.
  • BUILD — placement rules and price, analogous to the hex BUILD section.
  • LEVELS — per-level upgrade costs, income values, and stat modifiers. Rows are added/removed dynamically and keyed to the Max Level value.
Building data is stored independently from the Hex DB. A building's Id is referenced by the map via settlement markers, not directly by hex tiles.
